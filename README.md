# Data Professionals Survey Dashboard

 **Project Overview**  
This project presents a comprehensive **Power BI dashboard** analyzing survey data from data professionals worldwide. The interactive dashboard provides insights into **salary trends, job satisfaction, demographic patterns, and technical preferences** within the data industry.  

 **Dashboard Features**  

###  Demographic Insights
- **Total Respondents:** 630 professionals  
- **Average Age:** 29.87 years  
- **Geographic Distribution:**  
  - United States: 42.7% (269 respondents)  
  - United Kingdom: 24.76% (156 respondents)  
  - India: 21.27%  
  - Canada: 6.96% (44 respondents)  
  - Other Countries: 14 respondents  

### Salary Analysis
**Average Salary by Job Title:**  
- Data Architect  
- Data Engineer  
- Data Scientist  
- Database Developer  
- Data Analyst  
- Student / Looking for job  

### Job Satisfaction Metrics
- **Work-Life Balance Happiness:** 5.74 / 10  
- **Salary Satisfaction:** 4.27 / 10  
- **Difficulty Breaking into Data Field:** Analyzed across experience levels  

###  Technical Preferences
**Favorite Programming Languages:**  
- Python  
- R  
- SQL  
- Other specialized languages  

 **Technical Implementation**  

**Tools & Technologies**  
- Microsoft Power BI - Data visualization and dashboard creation  
- Power Query - Data transformation and cleaning  
- DAX - Custom measures and calculations  
- Data Modeling - Relationship establishment and data structure optimization  

**Key Metrics Calculated**  
- Average salaries by job title and experience  
- Demographic distributions and percentages  
- Satisfaction scores and trend analysis  
- Geographic concentration of data professionals  

 **Business Insights**  

**Key Findings**  
- **Salary Distribution:** Clear hierarchy in compensation across different data roles  
- **Geographic Concentration:** Strong presence in developed countries  
- **Satisfaction Gaps:** Work-life balance scores higher than salary satisfaction  
- **Market Entry:** Varying levels of difficulty breaking into the field  

**Actionable Recommendations**  
- Address salary satisfaction gaps in the industry  
- Develop targeted recruitment strategies based on geographic data  
- Create career path guidance for aspiring data professionals
